The one line a smart fridge texts its owner at 3am: a machine that has been awake all night, kept count of every midnight visit, and has finally decided to speak its mind.

## Run it

```sh
python3 main.py
```

Writes the 103-character line to `/output/entry.txt` (Python 3.13, standard library only).
